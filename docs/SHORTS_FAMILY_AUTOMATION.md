# 숏폼(가족) 랭킹형쇼츠 자동화

## 시작하기

1. `supabase/migrations/20260812_shorts_family_foundation.sql`을 Supabase에 한 번 적용한다.
2. 프로젝트 루트에서 `npm run dev`를 실행한다. 웹 앱과 로컬 영상 도우미가 함께 시작된다.
3. 사이드바의 **숏폼(가족)** 으로 이동한다.
4. STEP 1에서 **YouTube 전체 발굴**을 누른다. 특정 채널에 한정하지 않고 영어·일본어 가족/아기/어린이 랭킹 키워드를 합쳐 검색한다. 누적 1,000만 이상 또는 게시 7일 이내 300만 이상만 남기고 조회 속도로 정렬한다.
5. 원하는 영상의 **이 형식을 -ra 레퍼런스로 선택**을 누른다.
6. STEP 2에서 새 프로젝트를 만들고 `-ra` 영상을 5~7개 장면으로 자동 분리한다.
7. STEP 3에서 **전체 원본 자동 추적**을 누른다. Windows 로컬 비전 모델이 모든 장면을 분석하고 검색 후보를 만든 다음 실제 후보 영상의 프레임을 검증한다. 필요한 경우 개별 장면의 **이 장면 원본 찾기**로 다시 조사한다.
8. 원본을 못 찾은 자리는 보유 소스 검색에서 교체할 후보를 고른다. 선택한 장면 제목과 유사한 파일이 추천 순서로 먼저 표시된다.
9. 후보가 5개 이상이면 **제목·순위 자동 기획**을 누른다. 한국·일본 제목과 번역, 장면별 소재·감정·조회 원인, 서로 다른 국가별 순위를 검토한다.
10. 제목, 짧은 순위명, 좌우 반전, 자막 처리, 안전 검수를 확인하고 **Premiere XML·텍스트 생성**을 누른다.

## 출력 폴더

기본 위치는 `C:\Users\withj\Dropbox\해짜_소스모음\05_랭킹형쇼츠_프로젝트`이다.

- `00-reference`: 레퍼런스와 자동 분리 분석표
- `01-candidates`: 본편 후보 5~7개
- `04-source-info`: 출처 CSV와 최종 검수표
- `05-assets`: 국가별 로고와 무료 폰트
- `06-premiere`: 한국판·일본판 Premiere XML(`premiere-ko.xml`, `premiere-ja.xml`)과 같은 순서의 제목·순위 텍스트(`title-ranking-ko.txt`, `title-ranking-ja.txt`)

자동화는 영상을 렌더링하지 않는다. 클립을 세로 1080×1920 프레임에 꽉 차도록(cover) 스케일만 적용해 순서·트림대로 이어 붙인 XML과 제목·순위 텍스트만 만든다. 클립 사이 전환·페이드는 넣지 않는다(하드 컷). 그래픽·색보정·전환 효과는 아래 템플릿 기준을 참고해 Premiere에서 직접 작업한다.

## 템플릿 참고 기준 (Premiere 작업 시 수동 적용)

- 세로 1080×1920, 20~50초, 5위부터 1위까지 재생
- 한국판과 일본판 순서를 독립적으로 지정
- 국가별 기본 좌우 반전 2개, 원본 파일은 변경하지 않음
- 한국 순위명은 공백 제외 4글자 이내
- 가로 영상은 동일 영상을 확대한 블러 배경 위에 중앙 배치
- 명도와 채도를 소폭 보정하고 장면 전환에 짧은 암전 적용
- 자막 처리는 자동 확대, 강한 크롭, 하단 블러, 유지 중 선택
- 한국판은 강아지 로고와 컬러 순위, 현재 순위 100%·나머지 50%
- 일본판은 고양이 로고와 2단 제목, 현재 순위 빨간 밑줄
- 불필요한 하단 검은 설명 상자는 만들지 않음

## 원본 조사와 검수

후보의 **이 장면 원본 찾기**를 누르면 대표 프레임을 분석하고 YouTube·Google 검색 후보를 화면에 표시한다. 후보를 채택하면 로컬 라이브러리에 내려받아 해당 장면을 교체한다. 자동 결과는 원본임을 보증하지 않으므로 링크의 실제 일치 장면과 게시일을 직접 확인한다. 아동 위험 장면, 기존 자막·워터마크, 반전 시 문자 왜곡도 최종 검수표에 따라 확인한다.

## Windows 로컬 원본 추적 엔진

이 PC에는 Ollama와 `gemma4:e2b-it-qat` 비전 모델이 설치되어 있다. 재설치가 필요할 때만 다음 명령을 실행한다.

```powershell
npm run shorts-family:setup-vision
```

로컬 처리 순서:

1. 각 분리 장면에서 처음·중간·마지막 대표 프레임을 만든다.
2. Gemma가 장면별 OCR, 워터마크, 사람·행동·사물·장소를 분석한다.
3. 일반적인 문구 대신 고유한 자막·행동 조합으로 검색어 네 개를 만든다.
4. 장면마다 원본 후보를 최대 네 개로 줄인다.
5. 후보 3개씩, 장면 2개씩 병렬로 480p 검증 영상을 내려받는다.
6. 확대·크롭·자막을 견디는 영상 지문으로 프레임을 비교해 55점 이상만 표시한다.

첫 테스트 프로젝트 5개 장면의 로컬 멀티모달 분석은 약 57초가 걸렸으며 RTX 3060 GPU를 100% 사용했다. 네트워크 후보 검증 시간은 후보 서버와 영상 길이에 따라 추가된다.
