# 독립 댓글수집기

올인원 메뉴 → 댓글수집기 (`/comment-collector`). 숏튜디오 프로젝트를 만들거나 수정하지 않습니다.

- 유튜브 영상·Shorts: 서버의 기존 YOUTUBE_API_KEY로 최상위 댓글을 100개씩 수집합니다. 관련도순/최신순으로 요청하며, 좋아요순 표시는 현재 수집한 범위에만 적용됩니다. 최대 1,000개, 답글 제외.
- 인스타그램 게시물·릴스: 이 PC의 로컬 올인원에서 연결된 크롬 확장프로그램을 사용합니다. 로컬 제작실의 `/api/standalone-comments`가 댓글 읽기 요청만 전달합니다. 읽은 범위·좋아요 미표시·접근 실패를 표시합니다. 웹 배포본에서는 이 PC의 올인원으로 안내합니다.
- 검색, 선택 복사, 선택 또는 검색 결과 CSV/JSON 저장. CSV는 UTF-8 BOM과 수식 실행 방지를 포함합니다. 원문·작성자·좋아요·출처 보존.
- 최근 5개 영상은 로그인 계정별 브라우저 저장소에 보관합니다. PC 간 동기화는 하지 않습니다. 재수집 실패 시 기존 결과를 유지합니다.

새 로컬 댓글 연결 경로는 제작실 재시작 후 반영됩니다. 크롬 연결·Instagram 로그인은 `/browser-connect`에서 확인합니다. API 키는 브라우저에 전달하지 않습니다.

검사: `node --test scripts/check-comment-collector.mjs`, `npx tsc --noEmit`, 변경 파일 ESLint. 로컬 연결은 `pipeline/test_standalone_comments.py` 검사. YouTube 공식 사양: https://developers.google.com/youtube/v3/docs/commentThreads/list

## 영상용 PNG (2026-10-08)

읽은 댓글 중 좋아요순 최대 20개를 표시하며 추가 수집 버튼은 노출하지 않습니다. 전체 게시물의 절대 좋아요 상위 20개를 보장하는 순위는 아닙니다. 수집 원문과 최근 기록은 보존합니다.

댓글의 `이 댓글 PNG 만들기`로 원문을 선택해 어두운 카드로 저장합니다. 랜덤 닉네임/프로필 색상, 닉네임 및 프로필 블러 기본 적용, 불투명도 90%. PNG 문구를 편집해도 원문은 바뀌지 않습니다.

기본 1080×1920 투명 프레임, 대사 자막 끝 y=1380 + 간격24 → 카드 상단1404. 상단 제목 기준이 아닙니다. 너비900 중앙 배치. 위치/너비/글자크기/불투명도를 이 브라우저에서 기억합니다. 자막 안내선과 체크무늬는 저장되지 않습니다. 움직이는 자막 자동 추적은 정적 PNG의 기능이 아니며 동일 자막 위치 기준입니다. 카드만 PNG도 선택 가능. 화면 밖 문구는 잘라 저장하지 않고 길이/크기/위치 수정을 안내합니다.

검사: `node --test scripts/check-comment-png.mjs scripts/check-comment-collector.mjs`; 실제 브라우저 다운로드 RGBA/1080×1920/alpha0~230/위치 경계 검사.

## 영어 + 한국어 카드 (2026-10-08)
기본 영어 원문은 본문 글자 크기의 약67%와 노란색(#ffe45c), 한국어 번역은 바로 아래 흰색으로 표시. 자동 번역 버튼은 서버의 기존 Gemini 키로 댓글 문구만 번역하고, 결과를 직접 수정할 수 있다. 실패 시 원문/기존 번역을 보존하고 오류를 안내하며, 빈 번역으로 이중 언어 PNG를 저장하지 않는다. 원문 수정 시 이전 번역을 비워 잘못된 조합을 막는다. 원문만 모드도 제공. 유튜브 관련도순은 추천순(관련도)로 이름을 설명하며 인스타그램 URL에서는 해당 유튜브 전용 선택을 비활성화.

## 작업 화면 배치 (2026-10-08)
데스크톱은 왼쪽 수집/좋아요순20개 목록/댓글편집, 오른쪽 고정 미리보기. 댓글 목록은 내부 스크롤, 세부위치/블러/최근기록/CSV는 접는 설정. 카드 크게/영상 위치 미리보기는 저장 방식과 분리하여 위치포함PNG를 카드크게 보고 저장 가능. 모바일은 위아래 한 열로 배치.
