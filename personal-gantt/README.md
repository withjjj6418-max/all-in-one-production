# 개인 일정 — 작업·루틴·간트차트

올인원 프로젝트에 설치한 개인용 일정 앱입니다.

- 올인원 루트에서 `npm run dev`를 실행하면 개인 일정 서버도 자동 시작합니다.
- 올인원 왼쪽 **개인 일정** 메뉴는 같은 웹사이트의 `/personal-planner/index.html`을 새 탭에서 엽니다.
- 올인원 `npm run build`는 간트차트를 함께 빌드해 `public/personal-planner`에 포함하므로 Vercel에서도 동작합니다. 기존 로그인 보호를 그대로 적용합니다.
- 단독 실행은 이 폴더의 `시작.cmd` 또는 `node server.mjs`를 사용합니다.
- Node.js만 있으면 포함된 dist로 실행할 수 있습니다. 수정하려면 이 폴더에서 `npm ci`, `npm run build`를 실행합니다.

Vercel 웹사이트에서는 로컬 서버 없이 사용할 수 있습니다. 단독 로컬 실행도 계속 지원합니다.

## 기존 데이터 유지

저장 키 `personal-gantt-v1`을 유지합니다. 데이터는 사이트 주소와 브라우저별로 저장되며 기기 간 자동 동기화는 하지 않습니다. 로컬 주소에서 작성한 작업은 로컬 앱의 백업으로 JSON을 받은 뒤 Vercel 웹사이트에서 복원해주세요. 기존 로컬 데이터는 삭제되지 않습니다.

개인 데이터는 Git에 포함되지 않습니다. Git에는 앱 소스와 실행용 dist만 기록합니다. 서버는 올인원 개발 서버를 종료해도 계속 실행되므로 독립적으로 사용할 수 있습니다.

자세한 조작법은 [사용안내.md](./사용안내.md)를 참고하세요.

## 데일리 루틴 간트 연결

간트차트 최상단의 데일리루틴 그룹은 루틴 보드의 데일리 항목을 직접 표시합니다. 프로젝트·차수 필터와 관계없이 맨 위에 유지되며 작업명 검색은 적용합니다. 표시 기간의 각 날짜에서 완료를 체크할 수 있고 루틴 보드와 같은 기록을 사용합니다. 이름 변경과 삭제도 함께 반영됩니다. 반복 루틴은 일반 작업으로 복제하지 않으며 자동배치 대상에는 포함하지 않습니다.
