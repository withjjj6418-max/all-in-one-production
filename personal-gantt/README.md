# 개인 일정 — 작업·루틴·간트차트

올인원 프로젝트에 설치한 개인용 일정 앱입니다.

- 올인원 루트에서 `npm run dev`를 실행하면 개인 일정 서버도 자동 시작합니다.
- 올인원 왼쪽 **개인 일정** 메뉴는 새 탭에서 `http://127.0.0.1:5186`을 엽니다.
- 단독 실행은 이 폴더의 `시작.cmd` 또는 `node server.mjs`를 사용합니다.
- Node.js만 있으면 포함된 dist로 실행할 수 있습니다. 수정하려면 이 폴더에서 `npm ci`, `npm run build`를 실행합니다.

이 PC 전용 서비스이며 인터넷에 게시되는 기능은 아닙니다. 다른 기기에서 메뉴를 누르면 그 기기 자신의 로컬 주소로 연결됩니다.

## 기존 데이터 유지

기존 주소와 저장 키 `personal-gantt-v1`을 그대로 사용합니다. 같은 브라우저에서 열면 이전 작업, 루틴, 링크, 첨부가 유지됩니다. 소스 파일을 이동해도 브라우저 데이터는 이동하거나 삭제되지 않습니다. 브라우저가 다르면 앱의 JSON 백업·복원으로 옮겨주세요.

개인 데이터는 Git에 포함되지 않습니다. Git에는 앱 소스와 실행용 dist만 기록합니다. 서버는 올인원 개발 서버를 종료해도 계속 실행되므로 독립적으로 사용할 수 있습니다.

자세한 조작법은 [사용안내.md](./사용안내.md)를 참고하세요.
