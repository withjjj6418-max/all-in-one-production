# 나의 작업실 — 개인용 간트차트

`시작.cmd`를 두 번 클릭하면 기본 브라우저에서 열립니다. 이 PC에 설치된 Node.js를 사용하며 로그인은 필요 없습니다.

접속 주소: http://127.0.0.1:5186

## 작업 관리

- 메인 화면은 작업대기 / 작업중 / 작업완료 보드입니다. 카드를 다른 칸으로 끌거나 카드의 상태 선택으로 변경합니다.
- 새 작업에서 프로젝트, 차수, 날짜, 예상 소요시간, 목표 마감일, 우선순위, 메모를 지정합니다.
- 작업 이름을 클릭하면 상세 내용을 수정합니다. 날짜 입력의 달력 아이콘으로 날짜를 선택합니다.
- 왼쪽 프로젝트 이름으로 필터링하고, 상단에서 차수를 선택하거나 작업을 검색합니다.
- 프로젝트 옆 +로 프로젝트를 추가합니다. 프로젝트 · 차수 관리에서 이름, 색상을 바꾸고 차수를 추가합니다.
- 작업이 연결된 프로젝트·차수는 작업의 분류를 옮겨야 삭제할 수 있습니다.

## 간트차트

- 막대 가운데를 드래그하면 전체 기간이 이동합니다.
- 왼쪽 끝을 드래그하면 시작날짜, 오른쪽 끝을 드래그하면 마감날짜가 바뀝니다.
- 날짜는 하루 단위로 조정됩니다. 막대나 작업명을 클릭하면 오른쪽 편집 패널이 열립니다. 제목·일정·차수·프로젝트 등을 수정하고 저장할 수 있습니다. 막대에 키보드 포커스를 둔 뒤 Enter 또는 Space로도 열 수 있습니다.
- 상단에서 표시 시작일, 6주~1년 표시 기간, 날짜 너비를 지정합니다.
- 드래그는 마우스 기준으로 검증했습니다. 좁은 화면에서는 달력 입력을 이용할 수도 있습니다.

## 자동배치 규칙

1. 전체 프로젝트 또는 왼쪽에서 선택한 프로젝트가 대상입니다. 차수·검색 필터와는 관계없습니다.
2. 배치 시작일, 목표 마감일, 하루 가능 시간, 작업 요일을 입력합니다.
3. 작업의 기존 시작날짜를 가장 이른 시작 가능일로 사용합니다. 앞당기려면 이 날짜를 먼저 수정합니다.
4. 미완료·비고정 작업을 배치합니다. 프로젝트별 배치에서는 다른 프로젝트의 미완료 작업도 예약 시간으로 계산합니다.
5. 고정 작업의 예상 시간을 해당 기간의 작업 요일에 하루 가능 시간만큼 앞에서부터 예약합니다. 이후 빈 시간에 다른 작업을 배치합니다.
6. 개별 목표 마감일과 전체 목표 마감일 중 빠른 날짜를 기준으로 정렬하며, 같은 마감이면 높은 우선순위가 먼저입니다.
7. 한 작업이 하루 시간을 모두 사용하지 않으면 같은 날 다른 작업도 배치합니다. 막대는 시작부터 종료까지의 기간으로 표시되어 같은 날짜에 겹쳐 보일 수 있습니다. 시간대별 캘린더는 아닙니다.
8. 주말 제외 여부는 선택한 요일을 따릅니다. 공휴일·휴가·작업 간 선후관계는 별도로 계산하지 않습니다.
9. 미리보기에서 목표 마감 초과 일수를 확인한 후 적용합니다. 불가능한 마감을 맞춘 것으로 표시하지 않습니다.

자동배치는 예상 시간으로 만든 계획입니다. 진행중 작업의 소요시간도 입력값 전체를 기준으로 하므로, 재배치 전에 남은 시간으로 조정하면 더 정확합니다.

## 저장과 백업

동일한 브라우저의 동일한 주소에 자동 저장됩니다. 다른 브라우저·PC와 자동 동기화되지 않습니다. 브라우저 데이터 삭제 전에 반드시 왼쪽 하단의 **백업**으로 JSON 파일을 보관하세요. **복원**은 백업 내용을 확인한 뒤 현재 데이터를 교체합니다.

되돌리기는 현재 실행 중 최근 20번의 변경에 적용되며, 새로고침하면 되돌리기 기록은 초기화됩니다. 작업 데이터는 유지됩니다.

## 원본과 구현

제공된 gant-chart-anipang3-main의 React 구조, 프로젝트·차수·작업 개념과 날짜 유틸리티(src/utils.js)를 기반으로 별도 개인용 화면과 일정 계산을 작성했습니다. 다운로드 폴더의 원본 소스, 팀 데이터베이스, 업로드 파일은 수정하지 않았습니다. 원본 팀 데이터는 이 개인용 버전으로 자동 이전하지 않습니다.

## 확인한 내용

- 빌드 성공, 일정 계산 테스트 통과.
- Edge 브라우저에서 작업 추가, 상태 변경, 새로고침 후 저장 유지 확인.
- 카드 드래그, 간트 막대 이동, 양 끝 기간 조정, 자동배치 적용, 되돌리기 확인.
- 프로젝트·차수 추가와 데스크톱·좁은 화면 배치 확인.

개발 수정 시 `npm install`, `npm run dev`를 사용하고 배포 파일 갱신은 `npm run build`로 합니다.

## 데일리·위클리 루틴과 우선순위 매트릭스

왼쪽의 루틴 보드 메뉴에서 데일리·위클리 루틴과 우선순위 매트릭스를 사용할 수 있습니다. 작업 보드와 간트차트는 별도 메뉴로 유지됩니다. 프로젝트·차수 필터와 관계없이 표시됩니다.

- 데일리 루틴: 목록은 매일 반복되고 완료 여부는 선택한 날짜별로 기록됩니다. 화살표나 달력으로 지난 기록을 확인할 수 있습니다.
- 위클리 루틴: 목록은 매주 반복되고 완료 여부는 월요일~일요일 한 주 단위로 기록됩니다.
- 루틴 이름을 클릭하면 수정할 수 있습니다. ×로 삭제하며, 되돌리기로 삭제된 루틴과 완료 기록을 복구할 수 있습니다.
- 매트릭스: 긴급함/긴급하지 않음 × 중요함/중요하지 않음 네 칸에 자유롭게 입력합니다. 입력은 자동 저장됩니다. 작업 카드의 우선순위 및 자동배치와는 독립된 메모입니다.
- 루틴 목록·체크 기록·매트릭스 모두 기존 백업·복원에 포함됩니다. 이전 버전 백업도 읽을 수 있습니다.



## 작업 링크와 이미지 첨부

작업 편집에서 소요시간·개별 목표 마감일 입력은 제거했습니다. 시작날짜와 마감날짜는 그대로 사용합니다. 수정 저장 시 자동배치용 시간은 지정한 기간과 하루 작업 가능 시간으로 계산합니다. 자동배치 설정의 전체 목표 마감일은 유지합니다.

링크 주소를 붙여넣고 추가를 누르면 클릭 가능한 링크가 등록됩니다. 이미지를 복사한 뒤 편집 패널에서 Ctrl+V로 붙여넣거나 이미지 선택·드래그로 첨부할 수 있습니다. 썸네일을 누르면 크게 보며 ×로 삭제합니다. 저장하기를 눌러 첨부 내용을 저장하세요.

이미지는 최대 1600px JPEG로 압축됩니다(GIF는 정지 이미지). 브라우저 저장 용량을 보호하기 위해 전체 데이터가 커지면 저장 전에 이미지 축소 안내가 표시됩니다. 링크와 이미지도 JSON 백업에 포함됩니다.
